# Trend Rader

뉴스·YouTube·GitHub·DEV·요즘IT·네이버·다음·티스토리·Medium·WordPress·Reddit·뽐뿌·오늘의유머·디시인사이드·9GAG·Bored Panda 통합 검색 사이트입니다. 공개 RSS/API/검색 페이지에 반영된 범위이며, 전체 게시물 또는 초 단위 실시간 순위를 보장하지 않습니다.

## 실행

Node.js 22.13 이상에서:

```powershell
npm.cmd ci
Copy-Item .env.example .env
npm.cmd start
```

서버를 실행한 PC에서는 `http://localhost:3000`으로 접속하고, 같은 Wi-Fi/LAN의 다른 PC나 모바일에서는 서버 시작 로그에 표시되는 `같은 네트워크 접속` 주소로 접속합니다. Windows 방화벽 팝업이 표시되면 Node.js의 사설 네트워크 접근을 허용해야 합니다. 모바일은 서버 PC와 같은 Wi-Fi에 연결되어 있어야 합니다. HTML 더블클릭/Live Server만으로는 API가 작동하지 않습니다. 종료는 Ctrl+C입니다.

`.env.example`은 다른 기기에서 접속할 수 있도록 `HOST=0.0.0.0`을 사용합니다. 외부 인터넷에서 접속하려면 클라우드 호스팅 또는 공유기 포트 포워딩과 HTTPS 설정이 추가로 필요합니다.

## 채널과 인기 지표

| 채널 | 수집 범위와 해석 |
| --- | --- |
| Google 뉴스 | 지역별 주요 뉴스 또는 RSS 키워드 검색. 조회수 순위가 아님 |
| YouTube | 키 설정 시 공식 API: 빈 검색어는 지역 인기 차트, 키워드는 영상 검색. 키 없으면 공개 검색 HTML, 게시일은 추정치 |
| GitHub | 저장소 검색과 누적 별 수. 기간별 별 증가량이 아님. 날짜는 코드 push 시각 |
| 국내 블로그 | 네이버·다음·티스토리 사이트 한정 Google 뉴스 RSS 검색 |
| 해외 블로그 | DEV·요즘IT·Medium·WordPress 공개 피드 또는 사이트 한정 RSS 검색 |
| Reddit | 검색 RSS 또는 r/popular 피드 |
| 유머 | 뽐뿌 RSS와 오늘의유머·디시인사이드·9GAG·Bored Panda 사이트 한정 Google 뉴스 RSS 검색 |
| Google Trends | 지역 급상승 검색어 RSS. 표시 순서는 RSS 제공 순서이며 전체 검색량 순위가 아님 |

관련도 높은 순은 모든 채널의 결과를 합친 후 검색어 일치 비율 → 선택 국가 언어 → 제목·설명의 일치 점수 → 최신 시각 순으로 정렬합니다. 최대 100건 제한은 정렬 이후에 적용합니다. 최신정보 순은 전체 채널의 게시/갱신 시각 내림차순이며 같은 시각일 때 관련도·언어를 우선합니다. 새 검색의 기본값은 관련도순이며 기존 브라우저 저장 설정은 유지합니다. 플랫폼 간 조회수·추천 수를 같은 점수로 환산하지 않습니다. 기간 필터는 게시 시각 미제공 자료를 제외합니다. 추적 파라미터와 fragment를 제거한 URL로 중복을 판단하고 게시물 ID·영상 ID는 보존합니다. 다른 URL의 동일 기사까지 판별하지는 않습니다.

국가는 한국어·영어(미국/영국)·일본어·중국어 우선 수집에 적용됩니다. 뉴스의 지역판, YouTube의 지역·언어, 외부 요청의 언어 헤더를 설정합니다. 미리 정의된 분야 키워드(경제 등)는 현지 언어로 변환하지만 직접 입력한 검색어는 번역하지 않습니다. 일본 선택 시 note·はてなブログ, 중국 선택 시 CSDN·博客园의 사이트 한정 Google 뉴스 검색도 추가합니다. 자연어 필터가 없는 채널은 제목·설명 또는 제공 메타데이터로 언어를 추정합니다. 한자만 있는 일본어/중국어, 라틴 문자 언어는 완전히 구분할 수 없으며 선택 언어만으로 결과를 제한하지 않습니다.

Reddit은 RSS 게시물 검색에 type=link를 적용하여 커뮤니티 소개가 섞이지 않도록 합니다. 2분 캐시·동일 요청 공유·요청 간격을 적용하며 서로 다른 동시 요청은 빠르게 대기 안내를 반환합니다. 403(접근 제한), 429(요청 한도), 401(OAuth 인증), 네트워크·파싱 오류를 구분합니다. Retry-After와 OAuth 할당량 대기 시간을 따르며 차단 시 다른 호스트로 우회하지 않습니다. 동일 검색의 최근 15분 이내 결과가 있으면 원래 수집 시각과 이전 자료 안내를 유지합니다.

Reddit 접근이 계속 제한되면 승인받은 REDDIT_ACCESS_TOKEN과 실제 앱/연락 정보를 담은 REDDIT_USER_AGENT를 .env에 설정할 수 있습니다. 토큰은 서버에서만 사용하고 만료 시 직접 갱신해야 합니다. OAuth 승인 자체나 토큰 발급·자동 갱신은 이 앱에 포함되지 않습니다. [Reddit 공식 Data API 안내](https://support.reddithelp.com/hc/en-us/articles/16160319875092-Reddit-Data-API-Wiki)를 확인하세요.

- [Google Trends 급상승 검색어](https://support.google.com/trends/answer/3076011?hl=en)

API 활성화와 프로젝트 할당량 관리가 필요합니다. 공개 HTML/RSS 경로는 구조 변경 또는 접근 제한으로 실패할 수 있습니다.

## 사용자 기능

- 출처·분야·지역·기간·정렬 선택, 1분 자동 갱신. 숨겨진 탭에서는 자동 갱신 중지.
- 채널별 성공/실패, 조회/표시 건수, 응답 시간, 수집 시각 표시.
- 검색 조건 URL 공유·브라우저 저장, 화면 결과 CSV 저장. CSV 수식 시작 문자 무해화.
- 갱신 실패 시 이전 결과를 오래된 결과로 표시. 이전 검색 조건의 자료일 수 있음을 안내.
- Trends 실패 시 이 서버의 최근 24시간 수동 검색 기록으로 대체하며 범위 명시. 자동 갱신·실패한 요청 제외. 메모리 최대 10,000개, 재시작 시 초기화.

## 운영 동작

- 검색 캐시 60초, 일부 채널 실패 시 15초. 동일 검색 동시 요청 합치기, 다른 검색 최대 12개 동시 처리.
- 전체 출처 갱신 실패 시 동일 조건의 15분 미만 캐시만 stale: true로 반환. 원래 수집 시각 유지.
- Trends 지역별 5분 캐시, 실패는 30초 캐시, 동시 요청 합치기.
- 연결 IP별 API 분당 120회. 초과 시 429와 Retry-After. X-Forwarded-For를 신뢰하지 않으므로 프록시 뒤에서는 주소를 공유합니다. 공개 배포 시 프록시에서 사용자별 제한을 설정하세요.
- 외부 요청 timeout 12초, 일반 응답 최대 4MiB / YouTube HTML 8MiB. Reddit 별도 요청 간격 적용.
- RSS/Atom DTD 차단, HTML 텍스트 변환, 위험 URL 차단, CSP·프레임 차단, 정적 파일 allowlist.
- GET /api/health: 프로세스 생존 및 처리 중 검색 수. 외부 채널 정상 여부를 보장하지 않음.

## 검증 및 배포 범위

```powershell
npm.cmd test
```

파싱·안전 URL·검색 필터·공식 YouTube 분기·Trends 캐시·요청 제한·장애 시 캐시·화면 상태·CSV를 모의 응답으로 검증합니다. node probe.mjs는 실제 외부 피드 수동 점검입니다. 모의 테스트와 현재 외부 서비스 가용성은 다릅니다.

현재 구성은 단일 Node 프로세스 운영용입니다. 공개 배포 전 HTTPS 역방향 프록시, 프로세스 재시작, 오류 모니터링, 서비스별 이용조건 및 API 할당량을 설정해야 합니다. 다중 인스턴스에는 공유 캐시·요청 제한 저장소가 필요합니다. 수집 이력 영구 저장·회원·결제·알림·백그라운드 상시 수집은 포함하지 않습니다.
